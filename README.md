# Presentazione sito:
In questa repository c'è il materiale del sito "LeoparDig", di seguito elencato nel dettaglio. Sul sito sono attivi i link all'indice dell'edizione; ad un item, con file xml/tei e metadati; alla pagina strumenti e ai dati, visionabili e scaricabili in formato csv/json. 

## Materiale per il sito: 
1. homepage (index.html)
2. indice dell'edizione (indice_edizione.html)
3. pagina dell'item (item.html)
4. pagina degli strumenti (strumenti.html)
5. pagina dei dati (dati.html)
6. foglio di stile impiegato per il sito (style/style.css)
7. immagini richiamate nel sito (cartella img)
8. metadati item (metadati.xml)
9. tabella metadati (csv/json)
